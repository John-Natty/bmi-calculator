# Mini Project: BMI Calculator

This beginner-friendly Python project calculates a person's BMI.

BMI means Body Mass Index. It uses weight and height:

```text
BMI = weight / (height * height)
```

## What the program asks for

The program asks the user for:

* weight in kilograms
* height in meters

## What the program prints

Then it prints:

* the BMI rounded to 2 decimals
* a simple health category

## Error handling

The program also handles invalid input, such as:

* text instead of numbers
* zero values
* negative values

## How to run

Run the program with:

```bash
python3 bmi_calculator.py
```

On some systems, you may need to use:

```bash
python bmi_calculator.py
```

## Example

```text
Enter your weight in kilograms: 70
Enter your height in meters: 1.75
Your BMI is: 22.86
Health category: Normal weight
```
